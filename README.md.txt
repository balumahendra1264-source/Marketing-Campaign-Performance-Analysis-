# UPI Fraud Detection & Digital Payment Analytics

## Project Description
This project analyzes UPI transactions to identify fraudulent activities and understand digital payment patterns.

## Tools Used
- Microsoft Excel
- Power BI
- SQL
- Python

## Project Objectives
- Analyze UPI transactions.
- Identify fraudulent transactions.
- Analyze customer and merchant data.
- Find suspicious transaction patterns.

## Dataset
- Fraud Labels
- Merchants
- Transaction Data
- User Data
